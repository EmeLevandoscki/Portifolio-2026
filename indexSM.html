gestao_patrimonio_README.md

Sobre o Projeto

Sistema desktop para controle de patrimônio desenvolvido como projeto acadêmico. Permite cadastro, edição e visualização de ativos de uma organização.

Período

1º semestre de 2024

Como foi feito

A interface gráfica foi construída com PyQT5, proporcionando uma experiência desktop nativa em Python. O banco de dados MySQL armazena todos os registros com queries otimizadas para consulta e relatórios.

Tecnologias

Python MySQL PyQT5

Desafios

Integrar a interface gráfica com o banco de dados de forma eficiente, e projetar formulários responsivos dentro do PyQT5 que fossem intuitivos para o usuário final.

Resultado

Projeto aprovado na MIC (Mostra de Iniciação Científica) em 2025/1, reconhecido pela qualidade técnica e funcionalidade entregue.

crystal_of_atlan_macro_README.md

Sobre o Projeto

Macro desenvolvido a pedido de um cliente para automação de rotação de combate com foco na classe Silhueta no jogo Crystal of Atlan. Entregue em duas versões para atender diferentes necessidades.

Período

Abril de 2026

Versão Lua

Versão mais simples, com foco em um loop contínuo de habilidades. Funciona diretamente no ambiente do jogo, mas mostrou-se limitada para o caso de uso do cliente.

Versão AutoHotkey

Desenvolvida com base em leitura de tela. Utiliza um calibrador para capturar coordenadas de pixels específicos — quando o pixel muda de cor, indica que um buff está disponível e a lógica dispara a habilidade correspondente automaticamente.

Tecnologias

Lua AutoHotkey

Desafios

A versão Lua acabou não sendo utilizada por ser mais limitada. O verdadeiro desafio foi na versão AHK: identificar os pixels corretos na tela, calibrá-los com precisão e construir a lógica de detecção de mudança de cor para acionar os buffs no momento certo.
